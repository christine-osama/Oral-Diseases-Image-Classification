# Oral-Diseases-Image-Classification
Oral disease image classifier (6 classes: Calculus, Caries, Gingivitis, Hypodontia, Tooth Discoloration, Ulcers). Compares a custom CNN against fine-tuned EfficientNetB0, ResNet50V2, and DenseNet121, tunes the best backbone with Keras Tuner, and deploys via Gradio. Built with TensorFlow/Keras in Google Colab.
